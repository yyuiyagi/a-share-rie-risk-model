# A 股协方差谱去噪风险模型

> 一个关于"风险模型到底有没有用、有什么用、在 A 股上什么时候失效"的完整实证研究。

---

## 摘要

本项目**复现并验证**了一个协方差谱去噪（RIE）风险模型：用 Marchenko–Pastur 噪声尺度估计 + 尖峰非线性收缩，清洗 A 股样本协方差矩阵。核心结论是一句话——

> **去噪的价值不在"降波动"，而在"把风险量得更准（ρ）、更稳（换手）。"**

这条结论通过一系列可证伪实验得出：

1. 表面上，RIE 确实降波动、降换手、降回撤；
2. 但**风格中性化实验**证明，"降波动"里 **89% 是低波因子下注，纯去噪只占 11%**；
3. 去噪真正的、可迁移的价值是：**风险预测精度**（ρ = 0.371 vs 0.258）和**权重稳定性**（换手 1.8 vs 5.7）；
4. **qlib 2017–2020 反例**（RIE 跑输 naive）被中性化"治愈"（Sharpe −0.24 → +0.35），证明反例 100% 是隐性低波下注，不是去噪本身；
5. 方法对 A 股**结构性缺陷**（涨跌停截断让 σ 低估 28%、长尾）稳健，无需修；但在**崩盘**（跳跃/传染）中失效（全期回撤 −49.65%、微盘危机 bias 3.5）。

**定位**：这不是一个"收益策略"（比我们好的策略海量存在），而是一套**可迁移的诊断**——用第一性实验解释成熟风控体系（Barra/Axioma/risk-parity）里那些约束为什么存在、什么时候必要、什么时候失效。

## 1. 方法与数据

### 1.1 方法：RIE 谱去噪

对每个 252 日窗口，估计样本协方差矩阵 Σ，再做谱去噪：

1. **噪声尺度估计**：把标准化相关矩阵的特征值分布与 Marchenko–Pastur bulk 匹配，迭代求 $σ²$（$γ = N/T ≈ 1.98 > 1$ 时把正 bulk 均值除以 γ）。
2. **尖峰非线性收缩（RIE）**：对超过 bulk 上界 $λ₊ = σ²(1+√γ)²$ 的"尖峰"特征值，用反解公式 $θ = ([λ−σ²(1+γ)]+√([λ−σ²(1+γ)]²−4γσ⁴))/2$ 收缩到 $σ²+θ$；bulk 内特征值压成常数（保迹）。

### 1.2 数据与设置

- **数据**：A 股日收益面板（`data_tx`，qfq 优先，2015–2026，停牌线性插值）。
- **宇宙**：覆盖最完整的 500 只（偏大中盘；便捷宇宙，非逐日 PIT——已声明）。
- **回测**：纯 min-var（无 α）、月频（21 日）重平衡、单票权重上限 5%；长样本 OOS 2016–2026（123 期）。
- **对照**：`sample Σ`（未去噪）vs `RIE Σ`（去噪）。两者同特征向量、同标度，唯一差异是特征值变换——差异 100% 来自去噪。

## 2. 核心发现：四个验证维度

### 2.1 风险维度（实现波动 / 回撤 / 换手）

长样本（123 期）min-var：

| 指标 | sample Σ | RIE Σ | 变化 |
|---|---|---|---|
| 实现波动率 | 21.08% | 19.50% | −7.5% |
| 年化换手 | 5.7× | 1.8× | **−68%** |
| 最大回撤 | — | −49.65% | — |

（短样本 2022–2026 口径下,降波动 −12.6%、回撤 −4.1pp、换手 −69%。）

### 2.2 风险对齐（预测波动 vs 实现波动，方向 C）

关键：这把"尺子"需要**足够样本量**才有效。51 期时 ρ≈0（分辨不出），延长到 123 期后 ρ 显著：

| 模型 | ρ（t 值） | RMSE | MAE |
|---|---|---|---|
| sample | 0.258 (3.03) | 9.97% | 7.40% |
| **RIE** | **0.371 (4.71)** | **9.13%** | **6.68%** |

**RIE 的风险预测显著更准**——这是去噪价值的直接、干净证据。

### 2.3 风格中性化（拆开"风险控制"与"因子下注"，方向 A）

min-var 的 Σ⁻¹ 会天然重仓低波股——这是隐性低波因子下注。用权重约束把 low_vol/beta 暴露精确归零后：

| 中性化方式 | RIE 相对 sample 的降波动 |
|---|---|
| 无中性化 | 7.5% |
| 收益中性化 | 3.2%~3.6% |
| **权重约束（暴露=0）** | **0.8%** |

**结论：RIE 的"降波动"优势里，纯去噪只占约 11%，约 89% 来自低波/高 beta 因子下注。** 之前的"降波动有效"大部分是低波下注的伪装。

### 2.4 qlib 反例复测（验证预测 b）

qlib Alpha158（20 日 label）+ LightGBM，OOS 2017–2020（低波因子为负的 regime）：

| 组合 | 净夏普（非中性） | 净夏普（中性化） |
|---|---|---|
| naive（基准） | 0.380 | — |
| minvar | −0.711 | **+0.334** |
| tangency | −0.236 | **+0.347** |

**反例被中性化"治愈"**：中性化后 Sharpe 转正、净收益 +8.32% 几乎追平 naive。这证明 **qlib 反例 100% 是隐性低波下注的 regime 翻转，不是去噪本身的问题**。

## 3. 五个机制性发现（可迁移的结构规律）

1. **风险控制 = 隐性低波因子多头**：任何"降风险"工具（denoising/shrinkage/factor model/risk parity）都不是中性的，本质是 low-vol/low-beta 的多头。
2. **低波因子的收益符号随 regime 翻转**：防御 regime（2022–2026）低波股跑赢、进攻 regime（2017–2020）跑输——这就是 qlib 反例的根源。
3. **保迹去噪只改结构不改水平**：去噪重分配"哪些方向是因子、哪些是噪声"，不改总方差，所以对等权组合（不利用结构）无影响——去噪必须配"结构敏感的优化器"才有用。
4. **协方差模型的结构性断裂盲区**：崩盘是跳跃/传染驱动，历史协方差（去噪与否）都测不到——这是所有协方差模型的通病。
5. **风险对齐验证的统计功效依赖样本量**：短样本会把 ρ 稀释成假阴性，延长样本后差异才显现。

## 4. A 股结构性缺陷的影响

| 缺陷 | 实测影响 | 结论 |
|---|---|---|
| 涨跌停（截断） | σ 被低估 ≈26–28%（方差 ≈48%） | **对 min-var 稳健，无需修** |
| 长尾（重尾） | 尾部 1% 敏感度 ≈3%、2% ≈8% | 不偏差 σ，只让估计不稳定 |
| 封板密度 | 日均 ≈3%（涨停 1.8%、跌停 1.25%） | — |
| T+1 / 停牌 / 做空受限 | 回测成交假设偏乐观 | 报告已声明 |

关键修正：涨跌停是**截断**（把本该更极端的收益压到边界），所以它**压低 σ（低估）**，不是抬高。量化用的是"封板频率反推真实 σ"（σ_obs/σ_true ≈ 0.72），而非错误的"剔除封板日"。

## 5. 崩盘边界：什么时候防不住

| 崩盘窗口 | RIE min-var 区间回撤 |
|---|---|
| 2016-01 熔断 | −14.71% |
| 2018 熊市 | −40.08% |
| 2020-02 疫情 | −11.83% |
| 2022-01~04 熊市 | −18.75% |
| 2024-01~02 微盘危机 | −17.08% |
| **全期（2016–2026）** | **−49.65%** |

微盘危机段 bias ≈ 3.5（预测波动只有真实的 1/3.5）。

**方法声明**：谱去噪在**正常/高波动 regime** 有效（降波动、降换手、风险预测更准），但在**跳跃/传染驱动的崩盘**中失效——组合仍大幅回撤、模型严重低估风险。行业标准应对是叠加一层独立于协方差的压力测试 / 尾部 overlay。

## 9. 应用层：这个风险模型到底怎么用

### 9.1 核心场景：截面 alpha + 均值-方差优化

假设我们有一个截面策略，预测每只股票的期望收益 μ（截面 alpha）。要把它变成可交易的组合，标准做法是**均值-方差优化**：

> $\max μᵀw − (λ/2) wᵀΣw，s.t. w≥0, 1ᵀw=1$

- μ：截面策略预测的期望收益（alpha 信号）；
- Σ：协方差矩阵（就是本项目做的去噪 Σ）；
- λ：风险厌恶系数，控制"追 alpha"与"控风险"的权衡。

解是 w ∝ Σ⁻¹μ——权重 ∝ 风险调整后的预期收益。这正是本项目里"切点（tangency）组合"做的事，qlib 复测用的就是这个框架。

**去噪 Σ 在这里的真实作用**（结合本项目发现，诚实地说）：

1. **权重稳定、省成本**：去噪后 Σ⁻¹ 稳定，权重不因噪声跳变，换手从 5.7 降到 1.8——直接省交易成本。
2. **风险预测准、好控仓**：去噪 Σ 的 ρ=0.371（风险预测精度），能更准确地知道组合承担了多少风险，从而准确地设 λ 或目标波动率。
3. **正确惩罚相关性**：α 可能看好 10 只股票，但如果它们同属一个因子（高度相关），Σ⁻¹ 会自动降它们的权重，避免"以为分散了、其实没分散"的伪分散。

但不要指望去噪 Σ 显著提高 Sharpe——本项目已证明，"降波动"里 89% 是低波下注（regime 依赖）。去噪 Σ 的价值在**执行层（换手）和认知层（风险预测）**，不在收益层。

### 9.2 拼成一个 mini-Barra 优化器

把项目的所有产物组合起来，就是一个有行业对应的完整框架：

```
截面 alpha (μ)          →  收益信号
去噪协方差 (Σ)          →  风险结构（量得准、量得稳）
风格中性化约束 (wᵀF=0)  →  剥离隐性低波/高 beta 下注（方向 A）
目标波动 / λ 调仓       →  仓位控制（依赖 ρ 的准确度）
压力测试 overlay        →  声明崩盘边界（方向 B）
```

这实际上就是 Barra/Axioma 优化器的**极简版**：收益信号 + 风险模型 + 约束 + 边界声明。

### 9.3 展望（可落地的下一步）

1. **接入真实截面多因子策略**：把去噪 Σ 接进一个真实的截面 α，跑均值-方差，用 ρ（而非 Sharpe）验收风险模型是否改善了风险预测精度与换手。
2. **把 ρ 作为风险模型验收 KPI**：替代"能不能跑赢 baseline"，用"预测波动 vs 实现波动的对齐度（ρ）"作为风险模型的考核标准——这是方向 C 的核心启示。
3. **补 size/industry 中性化**：补市值、行业数据后，把中性化从 low_vol+beta 扩展到四因子，进一步剥离隐性下注。
4. **尾部 overlay**：在协方差模型之上叠加压力测试/尾部风险层，覆盖崩盘盲区（方向 B）。
5. **迁移到更高频/因子模型 Σ**：若 α 换手更高，Σ 可换 EWMA 短窗或结构化因子模型（Barra 风格）；本项目的方法论（ρ 验收、中性化、截断诊断）可原样迁移。

---

**一句话总结应用层**：这个风险模型是均值-方差优化的"刹车"——它不负责"跑得快"（那是 α 的事），它负责"刹车准、刹车稳"：让组合换手低（省成本）、风险算得准（好控仓）、相关性惩罚正确（不伪分散）。用它验收，该看 ρ 和换手，而不是 Sharpe。
