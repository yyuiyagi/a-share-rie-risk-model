## 2. 主文件：`returns_final`

**阶梯式日收益**，宽表 `date × instrument`，index 为交易日，columns 为 6 位代码字符串。

**每个格子的取值逻辑**（这是本面板的核心设计）：

| 优先级 | 口径代码 | 条件 |
|---|---|---|
| 1 | `q` | 前复权当日与前一日收盘均 > 0，且 \|ret\| ≤ 该股涨跌幅上限 |
| 2 | `r` | 前复权不可用，不复权有效且 \|ret\| ≤ 上限 |
| 3 | `x` | 两者都异常 → **置 NaN 并标记，绝不猜测** |

涨跌幅上限按板块与制度变更逐日判定：

```
688          → 20%
300/301      → 2020-08-24 起 20%，之前 10%
8xx / 4xx    → 30%
其余          → 10%
+ 5% 容差     （新股首日、ST 变更、四舍五入）
```

**实测效果**：

| | 原始单一口径 | 阶梯式 |
|---|---|---|
| \|ret\| > 0.30 | 3,712 | **0** |
| \|ret\| > 0.50 | 927 | **0** |
| 左尾 q0.0001 | -0.650 | **-0.150** |
| 右尾 q0.9999 | +0.515 | **+0.199** |

## 3. 为什么需要阶梯式：两个硬缺陷

### 缺陷 1：腾讯前复权对老股过度调整，出现**负价格**

| 窗口 | 非正价格占比 | 判定 |
|---|---|---|
| 1990–2014 | **12.78%** | ❌ 不可用 |
| 2015–2020 | 0.363% | ⚠️ 需清洗 |
| 2021–2026 | **0.007%** | ✅ 干净 |
| 2022 年起 | **0.000%** | ✅ 完全干净 |

全样本非正价格 550,660 / 8,474,316 行（6.5%），涉及 **559 / 1725 只**（32.4%）。
最严重的 `sh600809`：5203 / 7680 行价格 ≤ 0。

负价格序列上做 `pct_change()` 必然爆炸，这正是前复权口径出现 91,158 个
\|ret\|>30% 的根因。例：

```
sh600295  2007-04-11  open=-0.86  close=-0.94  r=-0.61
          2007-04-19  r=-3.60
```

### 缺陷 2：不复权序列含**拆股跳空，且无法用复权因子识别**

`sh600601` 在 1991-03-11 有约 5:1 拆股（价格 53.10 → 10.60），产生 -80% 跳空，
但**当天复权因子没有变化**。实测：不复权收益 < -15% 的下跌中，
伴随复权因子变化的有 **0 次**。

=> **不能靠复权因子定位拆股**，只能用"是否超过涨跌幅上限"这个物理约束来判定。

## 5. 基础池与幸存者偏差

**1725 只** = qlib **逐日成分股**（2017 行 / 1540 只，1999–2020-09）∪ 当前官方快照 500 只。

qlib 的 `instruments/csi500.txt` 格式为 `代码 \t 起始日 \t 结束日`，
每半年换手 50 只，共 1540 个不同代码——**这是无幸存者偏差的**。

⚠️ **但 2020 年之后没有官方历史成分数据**，该段仍是当前快照池。
**这一点必须在技术报告的「数据」章节显式声明**，不能含糊过去。

## 6. 读数据的正确姿势

```python
from qr_data import load_returns, load_source, load_quality, DEFAULT_WINDOW

R = load_returns(*DEFAULT_WINDOW)   # (2855, 1725) 宽表
S = load_source(*DEFAULT_WINDOW)    # 'q' / 'r' / 'x'

# 只要前复权口径（做稳健性对照）
import numpy as np
R_qfq_only = R.where(S == 'q')

# 收窄到中证500 成分（注意 2022 后无官方历史成分）
from qr_data import membership_mask
mask = membership_mask(R.index, list(R.columns))
R_csi500 = R.where(mask)
```

### ⚠️ 两个必须避开的坑

**坑 1：`instrument` 必须以字符串读。**
pandas 会把 `000005` 读成整数 `5`，使 `000005` 与 `000051` 合并成同一只股票，
产生完全虚假的收益率。`qr_data.py` 已在列名上做 `zfill(6)` 并断言为字符串。

**坑 2：读 `ret_source.csv.gz` 必须 `low_memory=False`。**
分块类型推断会抛 `IndexError: list index out of range`。`qr_data.py` 已处理。

## 7. 已知限制（写报告时照抄）

1. **2020 年后无官方历史成分股**，存在成分选择偏差。
2. **2015 年前的前复权数据不可用**（非正价格 12.78%）；`extended` / `full` 档位
   需额外清洗。
3. **不复权拆股跳空无法用复权因子识别**，仅靠涨跌幅上限过滤；理论上可能误伤
   极少数真实的大幅波动（但 A 股有涨跌停，超过上限的真实收益不存在）。
4. **停牌表现为日期缺口**（腾讯直接省略停牌日），而非零成交量行。
5. **数据止于 2026-09-30**，非实时。
6. 东财域在本机仍处封禁状态，如需换源须重新评估口径。
