# A 股协方差谱去噪风险模型（QR 项目）

复现并验证一个协方差谱去噪（RIE）风险模型，核心结论：

> **去噪的价值不在"降波动"，而在"把风险量得更准（ρ）、更稳（换手）。"**

## 目录结构

- `report/` —— 项目文档（`项目最终报告.md` 是完整报告）
- `qr_cov/` —— 代码（谱去噪、验证、诊断、风格中性化、崩盘分析）
- `results/` —— 结果输出（部分 CSV）
- `093111_1_5.0289031.pdf` —— 参考论文
